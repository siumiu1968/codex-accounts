# Codex Accounts 2.5.1 Change Notes

## 修改內容

- 將 macOS app 版本由 `2.5.0` 提升至 `2.5.1`，並同步更新 helper 初始化版本。
- 優化語言系統，將香港廣東話、書面繁體中文、簡體中文、英文和日本語分開處理。
- 修正香港廣東話介面被簡體字或書面中文規則污染的問題。
- 擴闊語言下拉選單，並改成按語言數量自動計算高度。
- 優化對話包匯出選擇器，支援勾選多條指定對話再匯出。
- 改善 quota cache 行為，避免部分 reset window 已過期時將整個 profile 顯示成未知。
- 對未能認證的 quota 狀態寫入明確 marker，避免舊 cache 被誤當成仍然有效。
- 新增本機 thread catalog 清理保護，移除已無 rollout/state 對應的 stale local thread row 前會先備份資料庫。

## 為什麼要這樣修改

- 原本語言切換只靠廣東話字串再轉繁體或簡體，導致廣東話顯示不準，甚至會出現簡體字。
- 對話包匯出原本一次只能選一條對話，不符合用戶只分享特定幾條對話的流程。
- quota 顯示曾多次因 cache、reset 時間或認證失效狀態混淆而顯示異常。
- stale local thread catalog row 會令 Codex 側邊欄出現不能恢復或點擊後消失的對話。

## 修改目的和影響

- 用戶可以更清楚地選擇「廣東話」、「繁體」、「簡體」、「English」和「日本語」介面。
- 匯出對話包時可以只包含被勾選的對話，降低誤分享整批對話的風險。
- quota 卡片在遇到暫時失效或認證問題時會顯示更穩定，不會輕易被過期資料覆蓋。
- 對話列表會自動清走本機 orphan catalog row，同時保留自動備份，降低資料修復風險。

## 安全和私隱

- 本次修改沒有加入任何 API key、cookie、token 或帳戶密碼。
- 對話包功能仍然預設不包含 auth、cookies、Codex config 或整個工作區。
- 如果用戶勾選附件選項，對話包可能包含被引用的生成圖片或工作區檔案，因此 UI 仍保留分享風險提示。
