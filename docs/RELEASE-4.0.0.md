# Codex Accounts 4.0.0

- App 版本：4.0.0（build 400）
- 系統需求：macOS 14 或以上；Apple Silicon 同 Intel 通用版。
- 下載：`Codex-Accounts-macOS.zip`

## 新功能

- **全新介面**：左邊導航（可拖動調整闊度）、帳戶列表、右邊詳情欄。粗額度條按剩餘量由綠變紅。
- **方案分組同置頂**：按帳戶實際方案自動分組（Pro 20x／Pro 10x／Plus／Free），可以手動修改；常用帳戶可以置頂同排序。
- **分析頁**：Token 總量、API 等值估算、快取命中率、AI 工作時間、每日用量、帳戶比較（每 1% 額度約等於幾多 Token）、額度規劃、建議、模型／推理級別／項目資料夾分佈、活躍時段熱圖、主對話同 Sub-agent、最多 Token 嘅對話。可以睇全部帳戶或者單一帳戶，7 日／30 日／全部。
- **每分鐘更新額度**：App 開住時每分鐘更新所有帳戶並記錄；登入失效嘅帳戶會隔耐啲先重試。
- **13 個主題**：每個都有深色同淺色，全部文字同主色通過對比度檢查；每個主題有自己嘅環境光暈。
- **自選背景圖片**：喺設定揀一張自己嘅圖；白底線稿會自動去走白色。圖片只會留喺本機。
- **螢幕清潔**：確認之後黑屏 15 秒並暫停觸控；撳 Esc 可以提早結束。
- **側欄開關**：防睡眠同鍵盤清潔可以喺側欄直接開關。

## 新安裝

- 第一次開啟會跟系統語言（廣東話、繁體中文、簡體中文、英文、日本語）。
- 缺少 `jq` 或 Python 3 時，帳戶頁會提示點樣安裝。
- App 入面唔包含任何帳戶資料、圖片或者建置者嘅路徑。

## 私隱

- 分析頁只讀 Codex 喺本機記低嘅用量數字、模型名同項目資料夾名，唔讀對話內容。
- 所有分析資料只存喺 `~/Library/Application Support/Codex Accounts/Analytics`，唔會上傳。
- 額度查詢同以前一樣，只用該 profile 自己嘅本機登入向官方接口查詢。
- API 等值按公開標準價估算，唔係實際收費。

## 已移除

- OpenCodex 模式（`opencodex-lab` 資料夾唔會被刪除，只係唔再顯示）。
- 對話冷儲存同低空間自動清理。

## 已知限制

- App 未經 Apple 公證，第一次開啟要喺「私隱與保安」揀「仍要打開」。
- 舊紀錄未必認得出屬於邊個帳戶，分析頁會標示為「未能歸屬」。
