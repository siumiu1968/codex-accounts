# Codex Accounts 4.0.1

- App 版本：4.0.1（build 401）
- 系統需求：macOS 14 或以上；Apple Silicon 同 Intel 通用版。

## 修正

- **繁體中文、簡體中文、日本語介面完整翻譯。** 以前呢三種語言只係由廣東話逐個詞替換，大部分句子冇變；而家全部 589 句介面文字都有正式翻譯，包括菜單、提示、彈出視窗、主題名稱、數字單位（億／萬）同星期。
- 簡體中文改用內地用詞（账户、登录、设置、屏幕等）。
- 有數值嘅句子會照樣帶入數值，日文會跟日文語序。
- 廣東話同英文冇改動。

## English

Complete Traditional Chinese, Simplified Chinese and Japanese interfaces. These languages used to be produced by swapping Cantonese words, so most sentences stayed unchanged. All 589 interface strings, including menus, messages, dialogs, theme names, number units and weekdays, now have proper translations. Cantonese and English are unchanged.
