# Codex Accounts V2.7.3

V2.7.3 加入低空間自動清理子 task，避免共享歷史因大量子 agent 複製上下文而再次填滿內置儲存空間。

## 重點

- 每分鐘檢查內置可用空間，少過 10 GB 先觸發，回升至約 20 GB 後停止。
- 只選擇 agent 建立、已封存、已完成，或者主 task 已繼續更新而停頓超過一小時嘅舊子 task。
- 永遠保留主 task、每組最新子 task、用戶建立 task，以及仍被程序開啟嘅 rollout。
- 原子更新共享索引，並清理各 profile 內對應嘅失效子 task 記錄。
- 清理記錄自動輪替，避免日誌本身無限增長。
- 保留 V2.7.2 嘅冷熱分層、直接 OpenAI 登入及記憶體輸出上限修復。
