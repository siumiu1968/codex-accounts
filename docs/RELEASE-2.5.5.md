# Codex Accounts V2.5.5

今次更新集中修復使用時間、登入狀態同介面顯示，亦加入更清晰嘅三段防睡眠控制。

## 修復

- 修正「今日使用」喺睡眠、斷電或異常關機後可能超過 24 小時；睡眠同關機時間唔會再計入。
- 登入狀態改以即時檢查為準，避免舊快取或暫時 403 將已登入帳戶誤標為未登入。
- 修正主題名稱顯示成省略號，以及主題卡片容易重疊嘅問題。
- 本機 proxy 改為自動偵測；只有 listener 真正可用先會注入，避免冇開 proxy 嘅電腦無法連線。

## 功能與介面

- 防睡眠改成三段彩色滑桿：關閉、開屏防睡眠、合蓋繼續運行。
- 合蓋模式需要 macOS 管理員確認；App 唔會保存管理員密碼。
- 退出時只會還原 Codex Accounts 自己開啟嘅合蓋設定，唔會關掉其他 App 或使用者設定嘅防睡眠。
- 主題整理成 8 款高辨識配色：石墨、極光、日落、霓虹、深海、櫻花、森林、午夜。
- 更新 GitHub 介紹同匿名示意圖；所有示意 profile、路徑同 quota 數值都係虛構資料。

## 私隱

- 公開版本唔再包含任何個人 profile ID 或本機使用者路徑預設值。
- 對話歷史錨點改為本機可配置設定；未設定時會安全使用 primary Codex profile。

## 安裝

下載 `Codex-Accounts-macOS.zip`，解壓後將 `Codex Accounts.app` 放入 `/Applications`。如 macOS 阻擋第一次開啟，可到「系統設定 → 私隱與保安」選擇「仍要開啟」。

> Codex Accounts 係非官方本機輔助工具，與 OpenAI 冇從屬關係。
