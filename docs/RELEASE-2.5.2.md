# Codex Accounts 2.5.2 Change Notes

## 修改內容

- 將 macOS app 版本由 `2.5.1` 提升至 `2.5.2`，並同步更新 helper 初始化版本。
- 修正左側欄語言切換卡片過闊，撞到側邊欄邊緣和白色 scroll indicator 的問題。
- 保留五種語言選項，但把語言切換卡片收窄到適合現有側邊欄的尺寸。
- 加強書面繁體中文和簡體中文的本地化轉換，避免「邊個」、「搵唔到」、「剔選」、「入面」、「掣」等廣東話詞語殘留在非廣東話介面。

## 為什麼要這樣修改

- 2.5.1 為了加入更多語言，將語言切換卡片加寬，但側邊欄原有上方空間不足，導致卡片貼近右側邊界並和滾動條視覺上撞在一起。
- 書面繁體和簡體模式仍然沿用部分廣東話原文，造成「繁體」或「簡體」介面語氣不一致。

## 修改目的和影響

- 左側欄頂部會重新留出足夠空間，語言卡片不再壓到邊緣。
- 廣東話模式仍保留香港口語；繁體中文和簡體中文會更接近書面介面文字。
- 修改集中在 UI 尺寸和本地化文字轉換，不會改動帳號、profile、token、cookie 或對話資料儲存邏輯。

## 安全和私隱

- 本次修改沒有加入任何 API key、cookie、token 或帳戶密碼。
- 本次修改沒有改變對話包、profile 同步或 quota API 的資料讀取範圍。
