# Codex Accounts V2.6.1

V2.6.1 將已完成嘅 Profile 啟動穩定修復正式發佈，並加入每個 Profile 獨立嘅私人本機對話模式。

## 打開 Profile 更穩定

- 「打開」操作改用獨立高優先序佇列，唔會再同一般背景整理互相阻塞。
- 正常啟動預設略過大型資料掃描同重型修復，縮短按掣後嘅等待時間。
- 關閉舊視窗後會等待程序真正退出，啟動後亦會確認對應 Profile 嘅 Codex 程序存在。
- 啟動失敗會顯示具體錯誤，唔再只係無限轉圈或表面上冇反應。
- 防止同一 Profile 重複打開，以及「關閉全部」同「打開」同時執行造成競態。

## 每個 Profile 嘅本機對話私隱

- Profile 選單新增「私人本機對話」同「共享本機對話」模式。
- 私人 Profile 會略過本機對話、記憶、「同步共享 Profile」同批量匯入共享。
- 新 Profile 預設使用私人本機對話，避免未經選擇就連到共享紀錄。
- 私人／共享切換會先檢查程序同資料庫狀態，並加入備份、驗證及失敗還原。
- 私人模式只隔離呢部 Mac 上由 Codex Accounts 管理嘅本機紀錄；使用 OpenAI 模型時，內容仍會傳送到 OpenAI 處理，唔係離線模式。

## 安裝

系統需求：macOS 14 或以上。

下載 `Codex-Accounts-macOS.zip`，解壓後將 `Codex Accounts.app` 放入 `/Applications`。如 macOS 阻擋第一次開啟，可到「系統設定 → 私隱與保安」選擇「仍要開啟」。

> Codex Accounts 係非官方本機輔助工具，與 OpenAI 冇從屬關係。
